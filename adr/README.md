# ADRs

Architecture decision records. In-progress plan: `PLAN.md` in the root (none when idle).

## Layout

- ADR: `adr/NNNN-title.md` — four digits, next free number, short kebab-case title. Context, Decision, Consequences; up to 20 lines. Immutable: a new ADR supersedes the old one, which is marked `Superseded by NNNN`.
- A number is never reused.
- A rule whose history an ADR tells links to the ADR; the ADR links back to where the rule lives ([conventions](../docs/conventions.md), [ARCHITECTURE](../docs/ARCHITECTURE.md), [development](../docs/development.md)).
